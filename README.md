Neon Harbor is an original top-down open-world crime game for the browser: a rainy neon city explored on foot and by car, with traffic, pedestrians, a wanted level and responding police, story missions, combat, a minimap HUD and a save system. Everything is drawn and synthesised in code, with no external assets.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
